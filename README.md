# ShopNest Amazon Affiliate Website

A modern, user-friendly affiliate product showcase website built with HTML and CSS.

## Features
- Creative, responsive design
- Premium product cards
- Amazon affiliate-style layout
- Mobile-friendly and easy to browse
- Updated category filtering buttons

## How to run
Open `index.html` in your browser directly, or serve it locally:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Important
Replace the sample Amazon links with your actual affiliate product links and your Amazon Associate tag before publishing.

```html
https://www.amazon.com/dp/PRODUCT_ID?tag=youraffiliateid-20
```
